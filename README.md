# Branch by Arboresce

> The creative path between 2 points is not a straight line.
>
> — the Branch team, *in conversation*

`branch-by-arboresce` is an application dedicated to the pursuit of creative exploration. It is designed to be an adaptive space where ideas can come together and apart and together and apart again. For iOS, Android, and desktop.

## Getting started

Start with the [setup guide](docs/development/setup.md) to prepare your development
environment and run the app. See [developer commands](docs/development/commands.md) to build, run, and verify the application.

## Repository

| Directory | Purpose |
| --- | --- |
| `core/` | Rust application state and runtime |
| `app/` | Mobile hosts, shared interface and native bindings |
| `contracts/` | Application identity and native build configuration |
| `docs/` | Architecture and development guidance |
| `scripts/` | Developer command routing |
| `tools/` | Binding generation and native build tooling |

See the [architecture](docs/architecture.md) for component ownership and the
[documentation index](docs/README.md) for further guidance.
