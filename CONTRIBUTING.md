# Contributing

Make small, reviewable changes with an imperative commit subject. Follow [repository
guidance](AGENTS.md), update the owning documentation and report verification results.
Use material you have rights to contribute and preserve attribution. Original
contributions use MIT OR Apache-2.0; see [NOTICE](NOTICE) for the artwork distinction.
Read [setup](docs/development/setup.md) and the [commands](docs/development/commands.md).
